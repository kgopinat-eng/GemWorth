# GemWorth

## About GemWorth

GemWorth is a Streamlit app for exploring diamond data and predicting prices in US dollars from carat weight and depth percentage. Users can upload data, create charts, and view model performance. Predictions are for educational use.

## Data Source

This project uses the **Diamonds** dataset, available on Kaggle:

https://www.kaggle.com/datasets/shivam2503/diamonds

The original dataset contains 53,940 diamond records, including
carat weight, cut, color, clarity, dimensions, and price in US dollars.

For this project, I removed the extra row-number column and duplicate
records. The default regression uses carat weight and depth percentage
to predict price.

The dataset is not a live market feed. Predictions are intended for
educational comparison, not current diamond appraisals.
